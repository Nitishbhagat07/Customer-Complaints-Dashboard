
# Customer Complaints Dashboard
Interactive Power BI dashboard to analyze customer support tickets.

## Tools Used
- Power BI

## What I Did
- Built a dashboard to analyze tickets by product, complaint type, priority and channel
- Created KPI cards, charts and a customer satisfaction gauge
- Tracked total complaints, resolved complaints and monthly trends
- Added a channel slicer to filter all visuals
- Found that only about one-third of tickets were resolved
